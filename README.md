# Patito linda

No soy bueno con las palabras, pero con esto sí.

Un libro digital para compartir pequeñas razones y mucho cariño.

## Sitio público

https://banymacajola.github.io/patito-linda/

El sitio se publica con GitHub Pages y no requiere iniciar sesión. Cada cambio que llegue a `main` inicia una nueva publicación.

## Ejecutar localmente

```sh
npm ci
npm start
```

## Comprobar y compilar

```sh
npm test -- --run
npm run build -- --base=/patito-linda/
```
